1. 템플릿 받기

현재 데이터(수정 중인 내용 포함)를 CSV로 내려받아 엑셀에서 가격을 고친 뒤 업로드하세요. 한글이 깨지지 않도록 UTF-8(BOM)로 저장됩니다.

가격표 기반 상품은 옵션 행(의무사용기간×방문주기)이 따로 있습니다. 옵션표 CSV는 첫 줄에 “옵션순번” 컬럼이 있으며, 그대로 수정해 다시 업로드하면 해당 제품의 옵션 배열이 통째로 교체됩니다(미리보기 후 적용). 일반 CSV의 월렌탈료·계약기간·관리주기는 옵션표에서 자동 계산되는 값이라 옵션이 있는 상품에서는 무시됩니다. 매트리스·에어컨 크리닝 가격표는 상세 편집(표 인라인 편집)에서 수정하세요.

2. 파일 올리기

CSV 또는 엑셀(.xlsx) 파일을 선택하세요. 적용 전에 변경 전 → 후 미리보기가 나오며, 확인 후 적용됩니다. (엑셀에서 "CSV (쉼표로 분리)"로 저장한 EUC-KR 파일도 자동 인식)

xlsx 는 SheetJS(CDN, 무결성 검증)를 처음 사용할 때만 불러옵니다. 첫 번째 시트를 읽습니다.

변경 내용 게시

저장소 의 파일을 직접 커밋합니다. 커밋 후 GitHub Pages가 자동 재배포되며 1~2분 뒤 사이트에 반영됩니다.

토큰 없이 수동으로 반영하는 방법
  1. "JSON 다운로드"로 price-overrides.json 을 받습니다.
  2. GitHub 저장소 cescoallcare/cesco-allcare → data 폴더 → Add file ▸ Upload files 로 같은 이름 파일을 덮어쓰고 Commit 합니다.

GitHub 토큰

⚠ 토큰은 이 브라우저(localStorage)에만 저장되고 GitHub 외 어디로도 전송되지 않습니다. 공용·남의 PC에서는 사용 후 반드시 "저장된 토큰 삭제"를 누르세요. 권한은 이 저장소 하나의 Contents 쓰기로만 만드세요.

토큰 만드는 방법

  1. GitHub에 cescoallcare 계정으로 로그인한 뒤 github.com/settings/personal-access-tokens/new 를 엽니다. (또는 오른쪽 위 프로필 ▸ Settings ▸ 맨 아래 Developer settings ▸ Personal access tokens ▸ Fine-grained tokens ▸ Generate new token)
  2. Token name: cesco-admin / Expiration: 90일 정도(만료되면 새로 발급) / Resource owner: cescoallcare
  3. Repository access ▸ Only select repositories ▸ cesco-allcare 하나만 선택
  4. Permissions ▸ Repository permissions ▸ Contents 를 Read and write 로 설정 (Metadata: Read-only 는 자동 포함, 그 외는 건드리지 않음)
  5. Generate token 클릭 ▸ github_pat_ 로 시작하는 토큰을 복사(한 번만 보입니다) ▸ 위 입력칸에 붙여넣고 "토큰 저장"
